# 🛡️ Discord бот: защита сервера + тикеты

Бот на **discord.py 2.x**. Умеет защищать сервер (анти-спам, анти-инвайт,
анти-рейд, анти-нюк) и вести систему тикетов с настраиваемой панелью.

## 📁 Структура

```
discord-bot/
├── main.py               # запуск бота
├── requirements.txt      # зависимости
├── .env.example          # шаблон для токена
├── utils/
│   └── storage.py        # хранение настроек по серверам (data.json)
└── cogs/
    ├── protection.py     # защита сервера
    ├── tickets.py        # система тикетов
    └── config_cmds.py    # команды настройки защиты
```

## 🚀 Установка

1. **Создайте бота** на https://discord.com/developers/applications
   → New Application → вкладка **Bot** → Reset Token → скопируйте токен.

2. **Включите Privileged Intents** (важно!) на вкладке **Bot**:
   - `SERVER MEMBERS INTENT`
   - `MESSAGE CONTENT INTENT`

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Создайте файл `.env`** (скопируйте из `.env.example`) и вставьте токен:
   ```
   DISCORD_TOKEN=ваш_токен
   ```

5. **Пригласите бота** на сервер с правами администратора (проще всего)
   или как минимум: Управление каналами, Управление ролями, Банить,
   Мутить участников, Просмотр журнала аудита, Управление сообщениями.
   Ссылка-приглашение: Developer Portal → OAuth2 → URL Generator →
   scopes: `bot` + `applications.commands`.

6. **Запустите:**
   ```bash
   python main.py
   ```

## ⚙️ Команды (слэш `/`)

### Тикеты
| Команда | Что делает |
|---|---|
| `/ticket_setup` | Задать категорию, роль поддержки и канал логов |
| `/ticket_panel` | Разместить панель с кнопкой в выбранном канале (можно задать свой заголовок и текст) |

**Порядок настройки тикетов:**
1. Создайте категорию (например «Тикеты») и роль поддержки.
2. `/ticket_setup category:Тикеты support_role:@Поддержка log_channel:#логи-тикетов`
3. `/ticket_panel channel:#создать-тикет` — появится кнопка «Создать тикет».

Пользователь жмёт кнопку → создаётся приватный канал. Внутри — кнопки
**Принять** (для поддержки) и **Закрыть** (сохраняет историю в лог-канал).

### Защита
| Команда | Что делает |
|---|---|
| `/set_log` | Канал для логов защиты |
| `/protection тип:антиспам включить:True` | Вкл/выкл конкретную защиту |
| `/whitelist_add` | Добавить доверенного пользователя (защита его не трогает) |
| `/whitelist_remove` | Убрать из белого списка |
| `/settings` | Показать все текущие настройки |

### 🪙 Экономика: магазин и отчёты
**Магазин с настраиваемыми товарами:**
1. `/shop_add` — добавить товар (название, цена, описание, эмодзи, роль-награда, склад).
2. `/shop_panel` — разместить магазин в канале (селект-меню + подтверждение покупки).
3. `/shop_remove`, `/shop_list`, `/shop_log` — управление и логи покупок.

**Отчёты на монеты:**
1. `/report_setup` — канал проверки отчётов, награда за одобренный отчёт,
   канал с кнопкой подачи.
2. Участник жмёт «📝 Подать отчёт на монеты» → заполняет форму → отчёт падает
   в канал проверки.
3. Админ жмёт ✅ Одобрить / ❌ Отклонить; при одобрении монеты начисляются
   автоматически, автору приходит ЛС.

**Баланс:** `/balance`, `/top` (топ-10), `/coins_add`, `/coins_remove` (админ).

### 🛡️ Защита (полный список)
Анти-спам, анти-инвайт, антиссылки, **анти-упоминания** (@everyone/@here и флуд
упоминаниями), анти-рейд, антибот, анти-нюк (каналы, роли, баны, кики,
**выдача опасных прав ролям**, **изменение настроек сервера**), усиленная защита
(предупреждения → автобан), белый список.

## 🧠 Как работает защита

- **Анти-спам** — если участник шлёт слишком много сообщений за короткое
  время, он получает мут и его сообщения чистятся.
- **Анти-инвайт** — удаляет ссылки-приглашения на другие серверы.
- **Анти-рейд** — при массовом заходе поднимает уровень проверки сервера
  и присылает предупреждение в логи.
- **Анти-нюк** — через журнал аудита ловит массовое удаление каналов/ролей
  и баны; у нарушителя снимаются роли. (Владельца и белый список не трогает.)

> Пороги (лимиты/интервалы) заданы в `utils/storage.py` в `_DEFAULT_GUILD`.
> Можно поменять под свой сервер.

## ⚠️ Важно про анти-нюк

Чтобы бот мог снять роли у нарушителя, **его роль должна быть выше**
роли нарушителя в списке ролей сервера. Также нужно право
**Просмотр журнала аудита**. По умолчанию анти-нюк снимает роли —
если хотите бан, замените логику в `protection.py → _punish_nuker`.
